# Feature entry template

Copy this block to the bottom of `FEATURES.md` and fill it in for the task
you just implemented. Keep it short — a few lines per field, not a full
spec/plan/tasks document.

```
## FEAT-<NNN> — <short title>

- **Reference:** <ticket/issue ID or URL, or "n/a">
- **Status:** Done | Partial | Blocked
- **Summary:** <1-3 sentences: what the feature does from a user's POV>
- **Files:** <comma-separated list of files added/changed>
- **Notes:** <anything a future agent needs to know: known limitations,
  follow-up work expected, deliberate deviations from the request>
```

Numbering: increment `NNN` from the highest existing entry in `FEATURES.md`
(zero-padded to 3 digits, e.g. `FEAT-001`, `FEAT-002`).
